# 4 Strong Gym Rajkot — Website Demo

Premium responsive website redesign concept for **4 Strong Gym Rajkot**.

## 🚀 Project Overview

This project is a modern fitness/gym website designed as a sales demo for 4 Strong Gym Rajkot.

The design uses a **turquoise, white, black and charcoal** visual system with a premium fitness aesthetic.

### Main Goals

* Present 4 Strong Gym professionally online
* Generate membership enquiries
* Make WhatsApp and phone contact immediately accessible
* Provide a strong mobile experience
* Showcase training options and gym facilities
* Provide a clear membership enquiry flow

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* Vanilla JavaScript
* Google Fonts
* Google Maps Embed
* WhatsApp Click-to-Chat

# ⚠️ Before Launching

This is currently a **sales demo**, not the final production website.

Before delivering it to the gym:

### 1. Replace demo images

The website currently uses temporary image URLs.

Replace them with:

* Actual gym interior photographs
* Equipment photographs
* Training photographs
* Trainer photographs
* Member photographs
* Exterior/signboard photographs
* Approved branding photographs

Use real photographs from the gym only after receiving permission.

### 2. Verify business information

Confirm with the gym owner:

* Phone number
* Address
* Opening hours
* Instagram account
* WhatsApp number

### 3. Add actual membership plans

The demo intentionally does not display invented prices.

Replace:

```text
ASK FOR MEMBERSHIP PLANS
```

with the gym's actual approved membership options and prices.

### 4. Add real testimonials

Do not use fabricated reviews.

Replace the testimonial placeholders with genuine customer reviews after receiving permission.

### 5. Add actual gym story

The About section currently uses general copy.

Replace it with information supplied by the gym owner about:

* Gym philosophy
* Facilities
* Trainers
* Training approach
* Services
